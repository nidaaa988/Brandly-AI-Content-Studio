# Brandly AI — Content Studio

A portfolio-ready static website based on the supplied Brandly AI project document and Figma prototype.

## Included
- Dashboard
- AI Captions Generator
- Social Media Post Generator
- Ad Copy Generator
- Content Ideas Generator
- Brand Templates
- Responsive layout
- Black + Orange + Cream visual direction
- Montserrat + Inter typography
- Interactive navigation and demo generation

## Run in VS Code
1. Extract this ZIP.
2. Open the extracted folder in VS Code.
3. Open `index.html` with a browser (or use the Live Server extension).
4. The site works without a backend.

## Important
The current generators are front-end demo generators, not a real AI API. A real OpenAI/Gemini backend can be connected later.
